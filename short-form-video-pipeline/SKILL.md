# Short-form video pipeline

## When
AI microdramas, kids music clips, YouTube Shorts / TikTok / Reels retention cuts.

## Structure that retains
1. Hook in 0–2s (face, twist, or visual punch)
2. Friction / desire
3. Twist or payoff beat
4. Cliff / loop for replay
5. Paywall or CTA only after a satisfying beat (dramas)

## Production flow
- Still / character refs first → motion prompts (avoid face drift)
- Short clips → assemble → dialogue/subs → mix
- Custom thumbnail before publish
- Made-for-kids flags only when content truly is for kids

## Platforms
- Open: TikTok, Shorts, Reels (audience first)
- Closed pay: ReelShort / DramaBox-style after proof of retention
- Kids music: channel location, audience setting, consistent brand

## Deliverables checklist
- [ ] Master + no-subs cut if needed
- [ ] Thumbnail
- [ ] Title/description keywords in audience language (pt-BR when Brazilian)
- [ ] Hook clip ≤15s for ads/posts
