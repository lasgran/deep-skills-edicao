# YouTube Shorts growth

Sources (MIT): vyralcontent/content-skills, AgriciDaniel/claude-youtube, Jakeschincariol/youtube-agent-skill, sergebulaev/youtube-skills, hassancs91/claude-faceless-shorts-creator, nateherkai/herk-edit-kit. Benchmarks are third-party heuristics, never guarantees.

## How Shorts are ranked
1. Viewed vs Swiped Away (VVSA): gate. <60% = broken opening; 70–90% = breakout range.
2. Average % viewed: ~65% (<30s), ~50% (30–60s), ~40–45% (60s+). >100% = loops firing.
3. Shares > comments > likes. Subscriber count barely matters; seed audience is mostly non-subscribers.
4. A Short can take off up to day ~4; push fades after ~30 days.

## Script
- Frame 1 is the hook. Speech starts at 0s. No logo, greeting or intro.
- First line: specific promise + curiosity gap. On-screen text for first 2s uses different words than the spoken line.
- Turn/stakes raise at 5–8s. Payoff must honestly close the open loop (max one main + one secondary loop).
- Last line sets up the first line so the video loops.
- No "subscribe" outro. Only CTA worth it: "full video on the channel" when a matching long-form exists.
- Length: shortest that delivers the payoff. Test ~13–20s vs 30–45s.
- Say the main keyword (name/topic) out loud; transcript and on-screen text are indexed for search.

## Edit
- 9:16 native, 1080x1920. No foreign watermarks; no 16:9-with-bars.
- Visual change about every 3s (new clip/angle/graphic). A still with a slow zoom is a finish, not a change. Keep zoom light.
- Burned-in, word-synced captions, consistent style, in the safe zone (avoid top ~20% and bottom ~25%).
- Original audio or no music on small channels; each licensed track cuts revenue share.
- Avoid mass-produced feel (AI voice over generic footage risks 'repetitive content' demonetization): authored script, specific point of view, varied visuals.

## Metadata
- Title 4–6 words / 20–40 chars, keyword first, promise not summary.
- Description: key info in first ~125 chars; 3–5 hashtags.
- Keep the Shorts tab on-topic; after a hit, post same-topic follow-ups. One strong Short beats several weak ones.

## Clips from long videos
- Pick 20–55s segments that start with a complete idea, contain a turn, and end on a sentence (no fade). Rewrite the first line/hook text so it works without long-video context.

## Diagnosing underperformance
Compare 5 best older vs 5 recent Shorts (VVSA, avg % viewed, retention curve, Engaged Views). Check in order: watermark, 9:16, first 3s, caption zone, ending CTA, music, Engaged Views. Early loss = fix script opening; sudden drop = cut that moment; steady bleed = tighten pacing. Change one thing and test on the next 3–5 uploads.

## Pre-upload checklist
[ ] hook at 0s  [ ] on-screen hook text ≠ spoken line  [ ] change every ~3s  [ ] captions in safe zone  [ ] loop closes  [ ] no subscribe outro  [ ] true 9:16, no watermark  [ ] keyword spoken + in title  [ ] audio rights OK
